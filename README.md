# Design Patterns in Java

This repository contains practical implementations of commonly used Design Patterns in Java.

## Patterns Covered

- **Adapter Pattern** – Allows incompatible interfaces to work together.
- **Bridge Pattern** – Separates abstraction from implementation.
- **Factory Pattern** – Creates objects without exposing the object creation logic.
- **Singleton Pattern** – Ensures that a class has only one instance.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
